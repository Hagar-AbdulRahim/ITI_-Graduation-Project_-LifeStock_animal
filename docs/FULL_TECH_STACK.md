# كل التقنيات المستخدمة في مشروع LifeStock Animal ووظيفة كل واحدة

---

## 🖥️ Backend (الواجهة الخلفية)

### بيئة التشغيل والإطار الأساسي

| التقنية | بتعمل إيه |
|---------|-----------|
| **Node.js** | بيئة تشغيل JavaScript على السيرفر — الأساس اللي المشروع كله شغال عليه |
| **Express.js** | إطار ويب لبناء الـ REST APIs — بيهندل كل الـ Routes والـ Middleware |

---

### قاعدة البيانات

| التقنية | بتعمل إيه |
|---------|-----------|
| **MongoDB Atlas** | قاعدة بيانات NoSQL سحابية — بتخزن كل البيانات (مزارع، حيوانات، حالات صحية، تطعيمات، مستخدمين) |
| **Mongoose** | مكتبة ODM — بتعمل Schema وmodels وvalidation لكل الـ Collections وبتسهّل التعامل مع MongoDB |
| **MongoDB Native Driver** (`mongodb`) | بنستخدمه مباشرة في الـ RAG Service عشان يتعامل مع `$vectorSearch` اللي Mongoose مش بيدعمها |
| **MongoDB Atlas Vector Search** | بحث بالتشابه الدلالي (Semantic Search) — بيدور في قاعدة المعرفة البيطرية بالـ Vectors مش بالكلمات الحرفية |

---

### الذكاء الاصطناعي (AI)

| التقنية | بتعمل إيه |
|---------|-----------|
| **Google Gemini 1.5 Flash** | النموذج الأساسي للذكاء الاصطناعي — بيعمل: التشخيص الطبي، محادثة الـ Onboarding، توصيات التطعيمات، توليد رسائل تحذير الفاشيات، وترجمة عناوين العيادات |
| **Gemini Vision** | نفس الموديل لكن بيستقبل صور — بيحلل صور الحيوانات المرضية ويحدد الأعراض الظاهرة |
| **Gemini Text Embedding** (`text-embedding-004`) | بيحوّل النصوص لـ Vectors رقمية عشان نقدر نعمل بحث بالتشابه الدلالي في قاعدة المعرفة |
| **Groq + Whisper Large v3** | بيحوّل التسجيلات الصوتية العربية لنص مكتوب — بيستخدم prompt بمصطلحات بيطرية لزيادة دقة التفريغ |
| **RAG System** (Retrieval-Augmented Generation) | نظام بيخلي الـ AI يبحث في قاعدة المعرفة البيطرية الأول (أمراض + تطعيمات) وبعدين يبني إجابته بناءً على بيانات حقيقية مش معرفته العامة |
| **Prompt Engineering** | تصميم prompts متقدمة فيها قواعد صارمة وخرائط قرارات — عشان الـ AI يرد بـ JSON محدد ويتبع خطوات معينة |

**الحزم:**

| الحزمة | بتعمل إيه |
|--------|-----------|
| `@google/generative-ai` | SDK الرسمي من Google للتعامل مع Gemini مباشرة (Chat + Vision) |
| `@langchain/google-genai` | غلاف LangChain لـ Gemini — بنستخدمه للـ Chat Model والـ Embedding Model |
| `@langchain/core` | النواة الأساسية لـ LangChain — بتوفر أدوات بناء الـ Chains والـ Agents |
| `@langchain/community` | إضافات مجتمع LangChain |
| `@langchain/mongodb` | ربط LangChain بـ MongoDB Vector Search |
| `@langchain/textsplitters` | تقسيم المستندات الكبيرة لأجزاء صغيرة قبل عمل Embedding ليها |
| `groq-sdk` | SDK للتعامل مع خدمة Groq (Whisper) لتحويل الصوت لنص |
| `pdf-parse` | قراءة واستخراج النصوص من ملفات PDF البيطرية لبناء قاعدة المعرفة |

---

### رفع الملفات

| التقنية | بتعمل إيه |
|---------|-----------|
| **Multer** | Middleware لاستقبال الملفات (صور + صوت) من الـ Frontend وحفظها على السيرفر |

عندنا 3 Middleware مختلفين:
- `Uploadaudio.js` — للملفات الصوتية فقط (حد 20MB، صيغ: webm, mp3, wav, m4a, ogg, aac)
- `Uploadimage.js` — للصور فقط (حد 15MB، صيغ: jpeg, jpg, png, webp, gif, jfif, bmp)
- `Uploadmixed.js` — للصوت والصور معاً في نفس الطلب (حد 25MB)

### الأمان والمصادقة (Authentication & Security)

| التقنية | بتعمل إيه |
|---------|-----------|
| **JWT** (`jsonwebtoken`) | توليد Access Token + Refresh Token لمصادقة المستخدمين |
| **bcryptjs** | تشفير كلمات السر قبل حفظها في قاعدة البيانات (هاشينج) |
| **cookie-parser** | قراءة الـ Refresh Token من الـ HttpOnly Cookies |
| **cors** | التحكم في مين يقدر يتواصل مع السيرفر (السماح للـ Frontend بس) |
| **express-validator** | التحقق من صحة البيانات المدخلة (إحداثيات GPS، أعمار الحيوانات، إلخ) |
| **Google OAuth** (`google-auth-library`) | تسجيل الدخول بحساب Google |
